# Income Calculator Bash Script

This is a simple interactive Bash script that helps users calculate their remaining monthly budget based on one or two income sources and their total monthly expenses.

## 📌 Features

- Accepts either 1 or 2 income sources
- Asks for post-tax income amounts
- Subtracts total monthly bills to show remaining budget
- Includes input validation
- Clean CLI interface and beginner-friendly logic

## 🛠 How to Use

1. Clone or download the repository
2. Make the script executable:
   ```bash
   chmod +x income_calculator.sh
